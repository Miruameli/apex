# 11 — Code of Conduct

## Prinsip

1. **Hormat** — kritik ide, bukan orang.
2. **Terbuka** — keputusan teknis di-share, tidak ada desain diam-diam.
3. **Jujur** — akui bug, jangan hackahut tutupi.
4. **Kontributif** — bantu orang baru, jawab pertanyaan, review PR dengan alasan.

## Tidak ditoleransi

- Harassment, diskriminasi, hate speech
- Spam, trolling, atau behavior yang mengganggu
- Klaim palsu atas karya orang lain

## Pelaporan

- DM ke maintainer (contact TBD). Semua laporan ditangani privat.

## Kontributor baru

- Selamat datang. Mulai dari issue yang labeled `good first issue`.
- Tidak ada pertanyaan bodoh. Tanya di issue/forum.
- Error = belajar. Tidak ada kecamanan.
