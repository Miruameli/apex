# 30 — Internationalization (i18n)

## Prinsip

- Default bahasa UI: **English** (per Q3: `apex.json` → `ui.language: "en"`, runtime override via `--lang`)
- Dokumentasi: **5 bahasa** (English `docs/en/`, Indonesian `docs/id/`, Chinese `docs/zh/`, Japanese `docs/ja/`, Korean `docs/ko/`) — struktur mirror tree lengkap; terjemahan iteratif mulai V1

## UI strings

Lokasi: `tui/src/i18n.ts` (TS), `apex/agent/prompts.py` (Python untuk LLM instructions).

Format (draft):

```typescript
// tui/src/i18n.ts
export const strings = {
  id: {
    welcome: "Selamat datang di Apex",
    thinking: "Memikirkan...",
    error: "Error",
  },
  en: {
    welcome: "Welcome to Apex",
    thinking: "Thinking...",
    error: "Error",
  }
};
```

## Agent prompts

Default system prompt di `apex/agent/prompts.py`. Bisa di-override via `APEX.md` (append/prepend).

## Dokumentasi

- `docs/en/` = English (primary untuk kontributor internasional)
- `docs/id/` = Indonesian (primary untuk kontributor lokal)
- `docs/zh/` = Chinese
- `docs/ja/` = Japanese
- `docs/ko/` = Korean

- `apex config --lang id` (V1)
- Default: auto-detect dari `$LANG` (V1)

## LLM language

- Agent merespons dalam bahasa user (prompt instruction)
- Code comments: per `APEX.md` rules (default: mengikuti bahasa proyek)
