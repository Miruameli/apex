## Scope anchors

- **Persona:** solo open-source developer (see [`01-product-spec.md`](01-product-spec.md)).
- **Platform:** terminal only — CLI and TUI. No web UI, no IDE extension.
- **License:** MIT, free forever, no paid tier.
- **MVP:** chat, review, commit/ship, skills, full TUI. Everything else follows.
